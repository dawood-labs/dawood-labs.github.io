# dawood-labs.github.io

Portfolio of Dawood Ahmad, live at https://dawood-labs.github.io

All content lives in `data/content.json` (person, impact numbers, projects, experience, publications, repos, skills, education, updates).
To update: edit `data/content.json`, run `python3 build.py`, commit and push. `build.py` regenerates `index.html` and `projects/*.html`.
